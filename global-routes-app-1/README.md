# Global Routes: London & Arab Destinations

## Overview
Global Routes is a web application designed to facilitate flight bookings between London and various destinations in the Arab world. The application provides users with an intuitive interface to search for flights, select departure cities, and manage their travel plans.

## Project Structure
The project consists of the following files:
- **index.html**: The main HTML file that contains the structure of the web application, including a header, a booking form, and a footer.
- **index.css**: The stylesheet that defines the visual appearance of the application, including layout, colors, and fonts.
- **script.js**: The JavaScript file that adds interactivity to the application, handling form submissions and user interactions.

## Setup Instructions
1. Clone the repository to your local machine:
   ```
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```
   cd global-routes-app
   ```
3. Open `index.html` in your web browser to view the application.

## Usage
- Enter your departure city in the provided input field.
- Select your desired destination from the dropdown menu.
- Choose your departure date and the number of passengers.
- Click the "Search Flights" button to submit your booking request.
